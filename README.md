# ZenDev — personal landing page

Статический сайт для GitHub Pages: HTML + CSS + JS, без базы данных и backend.

- Анимированная квадратная сетка на фоне.
- Плавные entrance/scroll-анимации.
- Раскрываемая подробная биография.
- Dreadshot расположен сразу после биографии и ведёт напрямую на Steam/Telegram игры.
- Никаких изображений, скриншотов, логотипов или API-запросов Steam.
- Копирование крипто-адресов одной кнопкой.

## GitHub Pages
1. Загрузите файлы в репозиторий.
2. Settings → Pages → Deploy from a branch.
3. Выберите `main` и `/root`.
