# ZenDev — personal landing page

Статический сайт для GitHub Pages. Без backend, базы данных и сборщика.

Особенности:
- киберпанковский terminal-style loading screen;
- интерактивная квадратная сетка и мягкий фон;
- лёгкий mouse-parallax на desktop;
- верхняя сине-фиолетовая полоса прогресса прокрутки;
- reveal-анимации при появлении блоков;
- раскрываемая биография;
- копирование крипто-адресов.
